\begin{abstract}
The short Wolo Code represents a geographic position by a locality reference and three words from a 1024-word dictionary. The locality reference identifies a city or an indexed regional anchor. The three words resolve to a point on a grid with nominal 2~m spacing. This paper proposes a Precision Wolo Code whose dot suffix identifies a decimal coordinate pair within the existing grid cell.
\end{abstract}

\begin{IEEEkeywords}
Geographic latitude longitude, word encoding
\end{IEEEkeywords}

\section{Introduction}
Words can make coordinates easier to communicate, enter, and remember. In the short format, the locality reference specifies the grid and the three words identify the rounded grid point. If the locality is implicit, the three words alone suffice to identify that point. Multiple input positions can share the same short code. The proposed precision suffix uses the grid cell to narrow the set of possible decimal coordinates. Exactness refers to the recovery of the encoded values. Measurement accuracy depends on the source.
\section{Theory}
Let there be a square grid G of N units.

where, \begin{equation}
N \label{eq:1} = 2^{L}
\end{equation}

and, L is Length in bits available for addressing one axis index of the two axes with any 3 of the 1024 words.

Since, \begin{equation}
2^{10} = 1024
\end{equation}

\begin{equation}
L = \frac{3 \times 10}{2} = 15
\end{equation}

thus, from (\ref{eq:1}):
\begin{equation}
\label{eq:4} N = 2^{15} = 32{,}768
\end{equation}

Let there be a city whose boundary is represented by circle S, within which the point P with global co-ordinates ($\phi$, $\lambda$) lies. Let the center of grid G coincide with the center C of the circle S, such that the grid encompasses the circle completely.

\subsection{Relative position} First we find the relative position of the given point P($\phi$, $\lambda$) on the grid G, as P$'$(x, y))

Let $\Delta$\ be the minimum distance in meters we want to resolve.
$\Delta$\ is thus the distance between two consecutive integral points of the grid on any given axis.

Then the total distance spanned by each side of the grid is:
\begin{equation}
D = N \times \Delta
\end{equation}

Let $\Theta$ be the angle that spans that total distance D.

Similarly, $\theta$ is the angle that spans that distance $\Delta$

The grid G's origin C$'$ has global co-ordinates:
\begin{equation}
C'_{(\mathrm{lat},\mathrm{lng})} = \left(C_{\mathrm{lat}} - \frac{\Theta}{2},\ C_{\mathrm{lng}} - \frac{\Theta}{2}\right)
\end{equation}

As we address only the integral points on the grid G, let P$'$ be the integral point closest to the given point P on the Grid.
All points within the square range R are rounded off to this same intersecting point P$'$.
The indices P$'$\textsubscript{x}, P$'$\textsubscript{y} of P$'$ will be based on the city it belongs to;
i.e. the city-center C of the closest city within whose range it falls.


Thus, \begin{equation}
P'_x = \operatorname{round}\left(\frac{P_{\mathrm{lat}} - C'_{\mathrm{lat}}}{\theta}\right)
\end{equation}

and \begin{equation}
P'_y = \operatorname{round}\left(\frac{P_{\mathrm{lng}} - C'_{\mathrm{lng}}}{\theta}\right)
\end{equation}

These indices must lie within range [0, N)

\subsection{Packing}
P$'$\textsubscript{x} and P$'$\textsubscript{y} are 15 bit numbers.
Thus totally they require 30 bits; and therefor: 3 - base-1024 numbers, to be packed into.
The relative latitude's (P$'$\textsubscript{x}) first 10 bits go into the first number of the output code W as W\textsubscript{1}. The relative longitude's (P$'$\textsubscript{y}) first 10 bits go into the second number W\textsubscript{2}. The remaining 5 bits of the relative latitude go into the first 5 bits of the third number W\textsubscript{3} and finally the longitude's last 5 bits go into its last 5 bits.

\subsection{City and Regional Locality Variants}
The output word code W$'$ specifies a grid point relative to a geographic reference origin. Two locality addressing formats are supported:

\subsubsection{City Variant}
For locations within a registered city boundary, the name of the city precedes the three words of output code W$'$.
\begin{center}
\textit{\textbackslash{}\textless city\textgreater\ \textless word\textsubscript{1}\textgreater\ \textless word\textsubscript{2}\textgreater\ \textless word\textsubscript{3}\textgreater/}
\end{center}
E.g. \texttt{\textbackslash{}Bangalore cat apple tomato/}

\subsubsection{Region Variant}
For locations outside registered cities, in rural, maritime, wilderness, or global areas, the system provides a named regional anchor reference. The globe is partitioned into half-degree anchor tiles ($360 \times 720$ tiles, each spanning $0.5^\circ \times 0.5^\circ$). Each named geographic region or administrative territory maintains a deterministic, frozen index of its intersecting global anchor tiles.
The code format is:
\begin{center}
\textit{\textbackslash{}\textless region\textgreater\ \textless index\textgreater\ \textless word\textsubscript{1}\textgreater\ \textless word\textsubscript{2}\textgreater\ \textless word\textsubscript{3}\textgreater/}
\end{center}
E.g. \texttt{\textbackslash{}Nepal 1112 candle kiwi mango/}\\
(or \texttt{\textbackslash{}India 1112 candle kiwi mango/})

Here, the numeric index identifies the 1-based local anchor tile within that region's namespace, establishing the local grid origin C$'$. The subsequent three words identify the rounded point on the nominal 2~m grid using the same 30-bit packing and 1024-word dictionary.

\subsection{Reversal}\label{AA}
The above process is reversed to obtain the coordinates of the rounded grid point P$'$ from the output code W:
\begin{equation}
P'_{\mathrm{lat}} = C'_{\mathrm{lat}} + P'_x \times \theta
\end{equation}

and

\begin{equation}
P'_{\mathrm{lng}} = C'_{\mathrm{lng}} + P'_y \times \theta
\end{equation}

\subsection{Total unique addresses}
From eq (\ref{eq:4}) the total addressable points T on the grid G become:
\begin{equation}
T = N \times N = 1{,}073{,}741{,}824
\end{equation}


\subsection{Resolution}
Targeting a resolution of 2 m, we set:
\begin{equation}
\Delta = 2\ \mathrm{m}
\end{equation}
Rounding to a valid grid point introduces up to half a step of error along each grid axis. The nominal grid span is
\begin{equation}
D = 65.536\ \mathrm{km}
\end{equation}

\subsection{Latitude adjustment}
The span angle $\Theta$ for latitude is independent of longitude but has to be adjusted based on latitude.
Since, the length of a degree of latitude is given by the following equation\cite{b2}
\begin{equation}
\Delta_{\mathrm{lat}}^1 = \frac{\pi\,a\,(1-e^2)}{180^\circ (1-e^2 \sin^2\phi)^{\frac{3}{2}}}
\end{equation}

Then the latitude angle $\theta\textsubscript{lat}$ spanning distance $\Delta$ with a resolution of 2 m, is given by:
\begin{equation}
\theta_{\mathrm{lat}} = 2\ \frac{1}{\Delta_{\mathrm{lat}}^1}
\end{equation}
and, the total span angle $\Theta$\textsubscript{lat} becomes:
\begin{equation}
\Theta_{\mathrm{lat}} = 2\ \frac{N}{\Delta_{\mathrm{lat}}^1}
\end{equation}

\subsection{Longitude adjustment}
As the lines of longitude converge at the poles, the distance spanned by them changes based on the latitude. It depends only on the radius of a circle of latitude. The length of a degree of longitude is given by the following equation\cite{b3}

\begin{equation}
\Delta_{\mathrm{lng}}^1 = \frac{\pi\,a\,\cos\phi}{180^\circ \sqrt{1-e^2 \sin^2\phi}}
\end{equation}

Then the longitude angle $\theta$\textsubscript{lng} spanning distance $\Delta$ with a resolution of 2 m, is given by:
\begin{equation}
\theta_{\mathrm{lng}} = 2\ \frac{1}{\Delta_{\mathrm{lng}}^1}
\end{equation}
and, the total span angle $\Theta\textsubscript{lng}$ becomes:
\begin{equation}
\Theta_{\mathrm{lng}} = 2\ \frac{N}{\Delta_{\mathrm{lng}}^1}
\end{equation}

\section{Precision Wolo Code}

A Precision Wolo Code consists of a short Wolo Code, a space-separated dot after its third word, and a space-separated suffix. The suffix starts with the decimal precision and ranks the input pair among the decimal positions within the short code's cell. Removing the suffix recovers the short code.

Let $p$ be the greater of the two supplied decimal-place counts, including trailing zeros, and let $S=10^p$. The decoder returns both axes to $p$ places. Use exact decimal or integer arithmetic on the source digits. The precision format uses the existing dictionary order and writes the most significant digit first.

\subsection{Ranking positions within a cell}
The precision profile for a reference fixes its grid origin, positive angular steps, and any reversible coordinate transformation into the grid frame. The web profile rounds the existing grid origin to 12 decimal places and the steps to 15, then treats those rounded values as exact decimals. The reference and its grid parameters must stay stable for previously issued codes. The transformation preserves the decimal lattice, as with reflection and translation by whole degrees.

For axis $j$, let $o_j$ be its origin, $d_j$ its step, and $i_j$ its short-code index. With halfway ties rounded toward the larger index, the first eligible scaled integer and the number of eligible integers are
\begin{align}
L_j &= \left\lceil S\bigl(o_j+(i_j-\tfrac12)d_j\bigr)\right\rceil,\\
n_j &= \left\lceil S\bigl(o_j+(i_j+\tfrac12)d_j\bigr)\right\rceil-L_j.
\end{align}
For the scaled input in the grid frame $(x,y)$, the rank is
\begin{equation}
r=(x-L_1)n_2+(y-L_2).
\end{equation}

\newpage
\subsection{Encoding the suffix}
Each axis offset must be in $[0,n_j)$. Encode $p$ in base 512, adding 512 to each digit except the last. Use no leading zero digit except for $p=0$. Then encode $r$ in exactly $k$ base-1024 words, padding with zero digits on the left. Use the least $k\ge0$ with $1024^k\ge n_1n_2$. A single eligible pair requires only the precision field.

\subsection{Decoding and validation}
The decoder reads the precision field through the first index below 512, computes the cell bounds, and divides the rank by $n_2$. The quotient and remainder give the two offsets. Reject invalid words or precision fields, empty cells, and incorrect rank lengths or values. The decoded pair must invert to valid geographic coordinates and reproduce the short prefix under its named reference. Use latitude and longitude directly when a stable, reversible grid profile is unavailable or grid normalization would discard an input value, as can occur at the poles or the antimeridian.

\subsection{Worked example}
For the coordinate pair $(28.2101130,83.9901909)$ in decimal degrees, the Nepal 45 short code has grid indices $(14173,28202)$. At $p=7$, the cell has scaled minima $(282101008,839901851)$ and axis counts $(180,203)$. Its rank is $24824$, yielding two rank words after the precision word.
